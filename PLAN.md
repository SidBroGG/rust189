# Генеральный план разработки клиента Minecraft 1.8.9 на Rust (Protocol 47)

- Направление разработки: Соревновательный, максимально оптимизированный клиент для мини-игр и сетевой игры на серверах.
- Технологический стек: Rust, wgpu, winit, egui, tokio, glam, rodio, flate2, serde.
- Первоисточники: Спецификация пакетов `ref/protocol-47.json` и оригинальные декомпилированные исходники MCP 1.8.9 `ref/net/minecraft/`.
- Правило исполнения плана: Строго один этап за один запрос пользователя с прохождением проверок и push на GitHub.
- Формат документа: Исключительно списки (маркированные и нумерованные). Использование таблиц, графиков и псевдографических схем исключено.
